# Contributing to HIOS

## Source of truth
Use HEDS as the engineering baseline, especially HEDS-003, HEDS-004, HEDS-005, HEDS-018, HEDS-021, HEDS-022, HEDS-023 and HEDS-030.

## Branching
- `main` — release baseline
- `develop` — integration
- `feature/<issue>-<slug>` — features
- `fix/<issue>-<slug>` — fixes
- `docs/<issue>-<slug>` — docs

## Pull requests
Every PR should include a linked issue, scope, acceptance criteria, test evidence and documentation impact.

## Definition of Done
Implementation complete, acceptance criteria met, tests pass, docs updated, no critical unresolved review comments.
