# Admin and Backoffice Foundation

Related issue: #13  
Source: HEDS-015 Admin Panel and Backoffice Manual, HEDS-025 Administrator Manual

## Purpose

This folder defines the initial admin/backoffice foundation for HIOS Phase 1.

## Current files

- `tenant-settings.md`: tenant settings map.
- `user-role-management.md`: user and role management flows.
- `audit-log-requirements.md`: audit log requirements.
- `sensitive-actions.md`: sensitive action checklist.
- `support-diagnostics.md`: support diagnostics baseline.

## Scope

Admin/backoffice scope covers tenant operations, support diagnostics, user/role management, and sensitive-action evidence. It does not replace API authorization or security controls.
