# HIOS Service Boundaries — Sprint 1 Baseline

## Initial domains
- Identity & Access
- Plant Registry
- Weather Integration
- Forecasting
- Generation Data
- Reports & Exports
- Alerts & Notifications
- Administration

## Cross-cutting concerns
- authorization
- auditability
- observability
- idempotency
- data lineage
- rate limiting
- error taxonomy

## Sprint 1 rule
Start as a modular monolith or clearly separated modules unless scale/isolation requirements justify decomposition.
