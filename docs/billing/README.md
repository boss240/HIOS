# Billing and Entitlements Foundation

Related issue: #14  
Source: HEDS-016 Billing, Subscription and Commercial Operations

## Purpose

This folder defines the initial billing and entitlement foundation for HIOS Phase 1.

## Current files

- `subscription-model.md`: subscription model draft.
- `entitlements-matrix.md`: entitlement enforcement placeholder.
- `commercial-operations.md`: commercial operations notes.
- `dependency-map.md`: billing/admin/API dependency map.

## Scope

Billing scope covers subscription state, entitlement profiles, commercial assumptions, and enforcement boundaries. Payment provider implementation is not selected in Phase 1.
