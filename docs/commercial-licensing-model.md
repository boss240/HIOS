# HIOS Forecast: модель ліцензування

## Предмет ліцензії

HIOS Forecast надається як **невиключна, строкова та непередавана ліцензія на користування сервісом прогнозування**. Клієнт зберігає права на свої дані СЕС, графіки споживання та завантажені цінові сценарії. HIOS не продає модель у власність клієнта та не виконує торгових дій на РДН.

Ціна визначається комерційною пропозицією після погодження потужності портфеля, кількості об'єктів, строку зберігання даних та рівня підтримки.

## Пакети

| Пакет | Для кого | Ліцензійна межа | Функції |
|---|---|---|---|
| Pilot | Перевірка на 1–2 СЕС | іменовані об'єкти, обмежений строк | погодинний прогноз, порівняння провайдерів, CSV/XLSX, звіт точності після actuals |
| Site | Власник однієї СЕС | одна СЕС або одна точка обліку | прогноз, read-only cloud integration, план споживання/РДН, API-експорт |
| Portfolio | Енергоменеджер | tenant та погоджена кількість активних СЕС/МВт | ролі, кілька об'єктів, погодинні сценарії, пакетні експорти, API |
| Enterprise | Інтегратор або великий портфель | договірна | SSO, SLA, white-label за окремим додатком, ізольований контур і інтеграції |

## Правила надання

- Облік ведеться за активними об'єктами у tenant та погодженою ліцензійною метрикою.
- Ролі: власник tenant, оператор, аналітик, API service account. Доступ до даних завжди tenant-scoped.
- Після завершення строку ліцензії сервіс переводиться у режим читання; експорт власних даних доступний за умовами договору.
- Дані прогнозу містять час випуску, інтервали, модель, джерела та прапорці якості — це доказова основа для аудиту.
- Прогноз є аналітичним інструментом. Клієнт самостійно затверджує графіки, ціни, заявки та диспетчерські рішення.

## Комерційний запуск

Пілот вимірює MAE, RMSE, bias та економічний ефект від погодинного планування. Перехід у Site або Portfolio відбувається після погодження фактичних даних, цільової точності та переліку інтеграцій.
