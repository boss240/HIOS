# Погодинний план, експорт та РДН

## Призначення

HIOS формує погодинний план на основі зафіксованого forecast run. До нього клієнт може додати два масиви, по одному значенню на кожний інтервал:

- `consumptionKwh` — планове споживання;
- `rdnPriceUahPerKwh` — затверджений ціновий сценарій РДН у гривнях за кВт·год.

Для кожної години розраховуються прогноз генерації, net grid, оцінка вартості імпорту та оцінка вартості експорту. Від'ємний `netGridKwh` означає очікуваний надлишок генерації.

HIOS не завантажує ціну РДН безпосередньо, не подає заявки, не керує інверторами та не змінює графіки споживання. Джерело ціни, одиниці, часовий пояс і рішення про використання має підтвердити оператор.

## API

`POST /forecast-runs/{runId}/hourly-plan` повертає JSON-план.

`POST /forecast-runs/{runId}/hourly-plan/export` повертає файл. Тіло запиту:

```json
{
  "format": "xlsx",
  "consumptionKwh": [12.4, 12.0],
  "rdnPriceUahPerKwh": [5.86, 5.44]
}
```

Підтримуються `xlsx` та `csv`. Дані авторизуються за tenant та доступні лише для підтвердженого immutable forecast run.

## Формула

`net grid = consumption − forecast generation`  
`import cost = max(net grid, 0) × RDN price`  
`export value = max(−net grid, 0) × RDN price`

Це сценарна оцінка, а не фінансовий результат чи торгове доручення.
