# Резервний імпорт погодинної генерації Deye

Цей шаблон застосовується, якщо OpenAPI Deye тимчасово недоступний. Він
призначений лише для двох пілотів: `deye-pilot-pohreby` та
`deye-pilot-borshchiv`.

## Файл CSV або Excel

Один рядок — один завершений погодинний інтервал. Заголовки обов'язкові:

| Поле | Значення |
| --- | --- |
| `plant_key` | Один із двох ключів пілота. |
| `interval_start_utc` / `interval_end_utc` | UTC у форматі ISO 8601, наприклад `2026-09-18T08:00:00Z`. |
| `ac_power_kw` | Середня або гранична AC-потужність лише після позначення її змісту в доказах. |
| `energy_kwh` | Енергія за інтервал. |
| `energy_semantics` | `interval` або `cumulative`. |
| `device_status` | Статус Deye, якщо присутній в експорті. |
| `source_reference` | Назва захищеного експорту або внутрішній номер джерела. |

Не включайте пароль, AppSecret, token, серійний номер інвертора, адресу або
повний необроблений JSON Deye. Коментарні рядки в CSV починаються з `#`.

## Карта даних Deye v1 — очікує підтвердження

| Потреба HIOS | Кандидат Deye | Одиниця / правило | Стан |
| --- | --- | --- | --- |
| Час кадру | `timeStamp` | Unix-час; timezone і межу інтервалу звірити | Очікує перевірки |
| Потужність AC | `generationPower` | Не переносити як kW без перевірки W/kW | Очікує перевірки |
| Енергія | `generationValue` | Визначити interval/cumulative і Wh/kWh | Очікує перевірки |
| Стан | Поле статусу з Deye export | Словник статусів Deye | Очікує перевірки |
| Прив'язка | `deye-pilot-pohreby` / `deye-pilot-borshchiv` | Фіксована для пілота | Підтверджено |

Після перевірки короткого експортного зразка HIOS створить незмінну версію
мапінгу, нормалізує дані до kW/kWh та лише тоді допустить їх до порівняння з
Google Weather і Solcast.
