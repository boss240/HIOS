# Mobile Foundation

Related issue: #12  
Source: HEDS-014 Mobile Application Specification

## Purpose

This folder defines the initial mobile application foundation for HIOS Phase 1.

## Current files

- `user-flows.md`: mobile user actions and flows.
- `push-notifications.md`: alert and push notification assumptions.
- `forecast-view.md`: mobile forecast view mapping.
- `offline-degraded-mode.md`: offline and degraded-mode assumptions.

## Scope

The Phase 1 mobile foundation is documentation-first. It defines app responsibilities, forecast screens, notification behavior, and degraded-mode handling before native or cross-platform implementation begins.
