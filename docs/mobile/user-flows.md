# Mobile User Flows

Related issue: #12

## Primary flows

### Review forecast

1. Open app.
2. Authenticate or resume session.
3. Select plant or dashboard summary.
4. Review forecast card, chart, and freshness indicator.
5. Open detail for table and provider context.

### Respond to alert

1. Receive push notification.
2. Open alert detail.
3. Review impacted plant and forecast state.
4. Confirm whether data is stale, degraded, or requires operator action.

### Check degraded status

1. Open plant detail.
2. View warning state.
3. Review last successful forecast timestamp.
4. Follow suggested next action or wait state.

## User actions

- Sign in / sign out.
- View dashboard summary.
- Search/select plant.
- View forecast chart.
- View forecast table.
- Review alerts.
- Refresh data where permitted.
- Manage notification preferences where permitted.
