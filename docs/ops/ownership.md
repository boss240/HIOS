# Operational Ownership

Related issue: #15

## Ownership areas

| Area | Initial owner boundary |
| --- | --- |
| API availability | Engineering / operations. |
| Forecast freshness | Forecasting / operations. |
| Weather provider integration | Forecasting / operations. |
| Data quality | Data / QA / operations. |
| Security evidence | Security / admin / operations. |
| Billing entitlement state | Billing / admin / operations. |
| CI and deployment | Engineering / operations. |

## Triage expectations

- Every alert category needs an owner.
- Incidents must preserve evidence and timeline.
- Customer-impacting forecast issues should link provider, forecast, and plant context.
- Security or audit-impacting events should be handled as sensitive operations.
