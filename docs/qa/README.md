# QA and Acceptance Framework

Related issue: #16  
Source: HEDS-018 QA and Test Strategy and HEDS-023 Technical Acceptance and Handover Manual

## Purpose

This folder defines the first QA and acceptance framework for HIOS Phase 1.

## Current files

- `test-categories.md`: initial testing categories.
- `release-gates.md`: release gate checklist.
- `defect-lifecycle.md`: defect workflow baseline.

## QA principles

- Acceptance criteria must remain traceable to GitHub Issues.
- API and data foundations must have documented verification gates.
- Security and tenant-boundary assumptions must be reviewed before release.
- Forecast quality checks must be defined before forecasting MVP acceptance.
