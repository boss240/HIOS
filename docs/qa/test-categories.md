# Test Categories

Related issue: #16

## Categories

| Category | Purpose | Phase 1 status |
| --- | --- | --- |
| Documentation review | Verify implementation docs and traceability | Active |
| Contract validation | Validate OpenAPI and API behavior | Planned |
| Data quality checks | Validate tenant, plant, forecast, and provider data | Active baseline |
| Security review | Validate auth, access, and audit assumptions | Planned |
| Forecast quality | Validate forecasting outputs and confidence metadata | Planned |
| Operational readiness | Validate logs, metrics, alerts, backup assumptions | Planned |
| Acceptance review | Final handover and release decision evidence | Active baseline |

## Evidence expectations

Each release candidate should list evidence for completed checks, known gaps, and accepted risks.
