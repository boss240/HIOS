# SLA and Legal Dependency Map

Related issue: #17  
Source: HEDS-029 Legal / Terms / Privacy / SLA Package

## Dependency map

| Dependency | Implementation impact |
| --- | --- |
| SLA availability | Requires uptime, incident, and recovery evidence. |
| Forecast freshness commitment | Requires forecast freshness metrics and alerting. |
| Data retention | Requires retention policy for user, plant, forecast, audit, and provider data. |
| Privacy policy | Requires personal data minimization and access controls. |
| Provider terms | May constrain storage, caching, and redistribution of weather data. |
| Support access policy | Requires audit and tenant-scoped diagnostics. |

## Open decisions

- Final SLA commitments.
- Weather provider licensing constraints.
- Audit retention period.
- Customer data export and deletion commitments.
